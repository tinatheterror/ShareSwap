Audit and fix responsive layout regressions across the app.

Problem:
Several pages including the homepage and navbar are morphing or rendering inconsistently across devices. Layouts are no longer flexing properly and some elements (especially logo/navbar areas) appear compressed, stretched, or broken on mobile/tablet widths.

Perform a full responsive layout audit and fix.

Requirements:

1. Audit shared layout wrappers.

Inspect:
- app shell
- navbar
- page containers
- dashboard/profile wrappers
- shared card layouts

Look for:
- fixed widths
- excessive min-widths
- overflow issues
- flexbox shrink problems
- broken grid breakpoints

2. Remove rigid sizing.

Replace problematic styles such as:
- width: fixed px values
- min-width values causing overflow
- hardcoded viewport widths

Prefer:
- w-full
- max-w-* containers
- responsive breakpoints
- flexible layouts

3. Fix flexbox shrink/compression issues.

Add:
min-w-0

to flex children where needed, especially:
- navbar sections
- card content
- profile layouts
- dashboard widgets
- pricing cards

Ensure children can shrink properly on smaller screens.

4. Audit navbar responsiveness.

Ensure:
- logo scales properly
- balance widget does not force overflow
- icons/buttons wrap or shrink correctly
- hamburger menu alignment stays stable
- no horizontal clipping occurs

5. Audit all grids.

Ensure all grids use responsive breakpoints properly.

Example:
- mobile: single column
- tablet: 2 columns
- desktop: 3+ columns

Avoid desktop grid counts applying to mobile widths.

6. Prevent horizontal scrolling.

The app should not horizontally overflow on:
- mobile
- tablet
- smaller laptops

Identify and fix any elements causing viewport expansion.

7. Preserve visual consistency.

Ensure:
- spacing remains balanced
- cards align cleanly
- typography scales correctly
- layouts feel intentional across breakpoints

8. Focus especially on recently added sections.

Audit:
- premium subscription cards
- dashboard/profile cards
- stat widgets
- inventory sections
- large modal layouts

These may have introduced regression styles affecting shared layouts.

Goal:
Restore a stable, responsive, flexible layout system that behaves consistently across all device sizes without compressed or broken UI sections.
